# Project overview

## Purpose
LabScope is a self-hosted infrastructure monitoring and diagnostic platform

## Target Audience
- Homelab administrators
- Linux server administrators
- Small infrastructure owners

## Core Features
1. Server monitoring
2. Docker monitoring
3. Network topology
4. Network diagnostics
5. Incidents management

## MVP Scope 
The first version will support:
- Linux hosts
- Docker containers
- CPU, RAM, Disk and Network metrics
- Manual network topology configuration
- Basic network diagnostics
- Incident notifications

## Out of Scope
- Kubernetes
- Automatic network discovery
- Infrastructure configuration management
- Multi-user permission systems
